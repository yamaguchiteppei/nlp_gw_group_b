# Slide Library（仮称）

PDF・PPTXをスライド単位で探し、過去資料の構成や表現を再利用するためのプラットフォーム。研究室での利用から始めるが、用途は研究発表に限定しない。

## 背景

過去のPPTXや、PPTXから変換してGoogle Driveに保管したPDFは、通常ファイル単位で管理されている。「研究背景を説明するページ」「モデル概要図」のようなページ単位の発見が難しい。Google Driveの「論文読み会」「言語処理学会」などのフォルダ階層も、検索・絞り込みに利用したい。

## 最初の目標

React/Vite・TypeScriptのフロントエンドとPythonのバックエンドで、**PDF・PPTXの登録、ページ単位の一覧・詳細表示と簡単な検索**を作る。画面はAPIを呼び、資料タイトル・著者・ページの見出し・概要の文字列、タグ、元フォルダで絞り込めるようにする。

開発中はモックデータで画面とAPIを先に確認する。これは実装手順であり、フェーズ1の完成条件ではない。Google Driveとの自動連携は後続段階で検討する。

## 開発順序

| 段階 | 到達点 |
| --- | --- |
| 1. Slide Library | PDF・PPTXを登録し、ページを表示・保存・絞り込みできる |
| 2. Drive連携 | 元のフォルダ階層を保ってPDFを取り込める |
| 3. 検索拡張 | タグ候補・Embedding・画像特徴などを評価して追加する |
| 4. 生成連携 | 検索したスライドを参考に編集可能なPPTXを制作する |

Design Studioは既存のデザイン比較手段で不足する要件が見つかった場合に、追加機能として検討する。
